# Практическая работа №9 (Big Data)

## Ход выполнения

1. Инициализируем FastAPI проект, реализуем три эндпоинта: для загрузки датасета, получения статуса и результатов обработки.
2. Далее создадим обработчика, который будет класть данные в Celery, чтобы модель обучалась в фоновом режиме на кластере Apache Spark.
3. Настроим Apache Spark кластер с мастер-нодой и воркер-нодой для распределенной обработки данных.
4. Создадим фронтенд на React для удобного взаимодействия с системой и визуализации результатов.
5. Реализуем pipeline машинного обучения с тремя основными компонентами: статистический анализ, обучение моделей и корреляционный анализ.

## Архитектура системы

### Компоненты

- **FastAPI Backend**: REST API для управления задачами
- **Apache Spark**: Распределенная обработка больших данных
- **Celery**: Асинхронная очередь задач
- **Redis**: Брокер сообщений
- **React Frontend**: Пользовательский интерфейс
- **Docker**: Контейнеризация всех сервисов

### Dataflow

1. Пользователь загружает CSV файл через веб-интерфейс
2. FastAPI сохраняет файл и создает задачу в Celery
3. Celery воркер забирает задачу и запускает обработку на Spark
4. Spark выполняет статистический анализ и машинное обучение
5. Результаты сохраняются в JSON формате
6. Frontend отображает результаты с интерактивными графиками

### Назначение МЛ в системе

#### Классификация

Задача - предсказать категорию объекта (А, В, С) на основе числовых признаков (value1, value2, value3).

Практический смысл - выявление скрытых закономерностей между числовыми характеристиками и категориями

#### Регрессия

Задача - предсказать значения value1 на основе value2 и value3

Практический смысл - оценка возможности восстановления отсутствующих данных, прогнозирование непрерывных значений на основе других параметров

#### Корреляционный анализ

Задача - измерить линейные взаимосвязи между числовыми переменными

Практический смысл - ппределение наиболее информативных комбинаций признаков
